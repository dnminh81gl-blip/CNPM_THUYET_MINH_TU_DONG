# Ảnh các điểm thuyết minh (POI) – Dinh Độc Lập

Lưu ảnh vào thư mục này, **đặt tên đúng theo id** của điểm, web tự hiện ảnh (không cần sửa code):

| File | Điểm |
|---|---|
| `poi-3.jpg` | Phòng Trình Quốc thư |
| `poi-4.jpg` | Phòng họp Nội các |
| `poi-5.jpg` | Sân thượng và trực thăng |
| `poi-6.jpg` | Tầng hầm chỉ huy |

Điểm 1 (Cổng chính) và 2 (Mặt tiền) đang dùng ảnh tự do trên Wikimedia Commons.

- Nên dùng **ảnh nhóm tự chụp** (khổ ngang, khoảng 1200×800, dưới 300 KB). Không lấy ảnh trên mạng khi chưa được phép.
- Thêm điểm mới ở trang Admin thì ô "Ảnh" nhập `img/places/poi-<id>.jpg`.
